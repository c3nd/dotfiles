# Milkdromeda Dotfiles ฅ^•ﻌ•^ฅ

NixOS + Home Manager configuration for the **Milkdromeda** host — a Hyprland +
[caelestia-shell](https://github.com/caelestia-dots/shell) workstation with an
NVIDIA/Intel Optimus (Prime) GPU setup.

These dotfiles are managed as a [Nix flake](https://nixos.wiki/wiki/Flakes).

---

## Structure

```
dotfiles/
├── flake.nix              # Flake inputs + the Milkdromeda system output
├── configuration.nix      # System-level NixOS config (boot, HW, networking, services)
├── home.nix               # Home Manager config for user `kepler452` (user pkgs, dotfiles)
├── packages.nix           # System-wide package list (grouped by category)
├── hardware-configuration.nix  # Auto-generated hardware scan (do not edit by hand)
├── modules/               # Reusable NixOS / Home Manager modules
│   ├── cake-wallet.nix    # Cake Wallet (binary release → system package)
│   ├── qtengine.nix       # qtengine Qt theme module
│   ├── atomic-chat.nix    # Atomic Chat AppImage wrapper (Home Manager, opt-in)
│   └── zcode.nix          # ZCode AppImage wrapper (Home Manager, opt-in)
└── config/                # User dotfiles, symlinked into ~/.config via home.nix
    ├── caelestia/         # caelestia-shell config (shell.json, hypr*, monitors/)
    ├── qt6ct/  qtengine/  # Qt theming
    └── zed/               # Zed editor settings
```

### How dotfiles get applied

`home.nix` uses `mkOutOfStoreSymlink` to point each `~/.config/<name>` at the
matching directory under `config/` in this repo. That means **editing a file
under `config/` takes effect live** (reload the app) without rebuilding the Nix
store — but you still commit & push changes here to keep them version-controlled.

## Layout of the Nix files

| File | Scope | Notes |
|------|-------|-------|
| `flake.nix` | Whole flake | Declares inputs (nixpkgs, Hyprland, caelestia-shell, browsers, etc.) and the `Milkdromeda` configuration. |
| `configuration.nix` | System | Boot loader, kernel, hardware (NVIDIA Prime), networking, firewall, printing, users, system packages. |
| `home.nix` | User | User packages, fish shell, git, caelestia session, Qt/GTK theming, Zed, dotfile symlinks. |
| `packages.nix` | System | Flat, *categorized* list of system packages consumed by `configuration.nix`. |

## Rebuilding

From the repo root (default `root` for system, since this configures the host):

```bash
# Apply the system + home configuration
sudo nixos-rebuild switch --flake .#Milkdromeda

# Just check that the flake evaluates (no build)
nix flake check
```

The fish alias **`plspush`** commits everything in this repo and pushes to
`origin/main`:

```fish
plspush   # => git add -A && git commit -m 'autocommit' && git push
```

## Optional app modules

`atomic-chat` and `zcode` are wired into `home.nix` but **disabled by default**
(their `hash` defaults to `lib.fakeHash`). To install one:

1. Set `programs.<name>.enable = true;` in `home.nix`.
2. Run `sudo nixos-rebuild switch --flake .#Milkdromeda` once — Nix will fail
   and print the *real* sha256 for the AppImage.
3. Paste that hash into the module's `hash` option (or directly in `home.nix`)
   and rebuild again.

```nix
programs.atomic-chat.enable = true;
programs.atomic-chat.hash    = "sha256-XXXX";   # from the build error
```

## Notes

- `system.stateVersion` is `25.11` in both `configuration.nix` and `home.nix`.
  Don't bump it lightly — see `man configuration.nix`.
- The firewall is intentionally disabled (single-user workstation behind a
  router). Re-enable in `configuration.nix` if this box is exposed.
- `hardware-configuration.nix` is generated by `nixos-generate-config` and may
  be overwritten on future hardware scans — keep machine-specific tweaks in
  `configuration.nix`, not here.
